# Pure fusions

One element taken twice. These are the easiest fusions to reach: a character's locked native infusion plus one more of the same element.

## Dragon — Fire + Fire

*Fire at its peak: a wyrm whose burns fill its hoard, whose hoard hardens its scales, and who spends it all on one breath.*

- **Dragonfire** (Debuff): counts as Ignite, but deals 10 Affliction at the end of its applier's turn instead of 5. Applied to an Ignited unit, it upgrades the Ignite.
- **Hoard** (the user's, max 6): +1 each time an Ignite or Dragonfire the user applied deals damage. Every 2 Hoard gives the user 1 Armor. **Breath** skills spend all of it for +5 damage per Hoard to each target, so breathing trades defense for burst.

## Cloud — Wind + Wind

*Wind that gathers instead of rushing: slow, telegraphed, and heavy when it breaks.*

- **Drift**: a Drift skill hangs in plain sight and lands at the start of the user's next turn, on the same targets if they're still valid (otherwise on another valid one). It still lands if the user is Stunned, but is lost if they die. Counters and Traps react when it lands. Drift skills cost less and hit harder than an instant version would.
- **Aloft** (Buff): the bearer counts as Leaping (+5 direct damage, and Wind's Leaping payoffs) for its whole duration; dealing damage doesn't end it. Unlike a Leap, it gives no Invulnerability.

## Evolution — Poison + Poison

*Poison that adapts: every use makes the skill stronger.*

- **Evolve**: each Evolution skill has three stages. It starts at Stage I and goes up one stage each time it's used, then stays at III. Each row gives Stage I, then what II and III change. Stages belong to the skill and both players can see them, so the enemy knows which skills to fear by the late game.

This kit has one new keyword on purpose: Evolve already rewrites every skill three times.
